╔══════════════════════════════════════════════════════════════════════════╗
║                       TROUBLESHOOTING                                    ║
╚══════════════════════════════════════════════════════════════════════════╝

  Problem: "Python is not recognized"
  Solution: Install Python 3.8+ from python.org (check "Add to PATH")

  Problem: Desktop mode doesn't work
  Solution: App automatically falls back to browser mode (same features)

  Problem: First launch takes too long
  Solution: Normal - installing dependencies. Subsequent launches are fast

  See DESKTOP_SETUP.md for complete troubleshooting guide.
