# New Features Guide

This document provides detailed information about the new features added to the Musicians Fraud AI Song Generator.

## 🗣️ Text-to-Speech Vocals

### Overview
The app now generates actual vocal tracks from your lyrics using advanced Text-to-Speech (TTS) technology, replacing the previous placeholder tones with real synthetic voices.

### How It Works
1. **Automatic Integration**: When you generate a song with lyrics, the system automatically creates vocal tracks
2. **Multiple Engines**: 
   - **gTTS (Google Text-to-Speech)**: High-quality online synthesis (recommended)
   - **pyttsx3**: Offline synthesis (fallback option, requires system audio drivers)
3. **Smart Fallback**: If one engine fails, the system automatically tries the next available option

### Usage
No special configuration needed! Just:
1. Generate or enter lyrics in the web interface
2. Select your preferred vocal type (Male, Female, Mixed, Choir, Rap)
3. Click "Generate Full Song"
4. The vocals will be automatically generated and mixed with the instrumental tracks

### Technical Details
- Vocals are generated by converting lyrics text to speech
- Section markers like `[Verse 1]` and `[Chorus]` are automatically removed
- Instrumental sections are kept silent
- Volume is automatically balanced with other instruments
- TTS audio is time-stretched or trimmed to match song structure

### Limitations
- gTTS requires an internet connection
- Voice characteristics are limited by the TTS engine capabilities
- Singing quality is synthetic (not human-like singing)

## 🎵 MIDI Export

### Overview
Every generated song now includes a MIDI file that can be used in Digital Audio Workstations (DAWs) and other music software.

### How It Works
1. **Automatic Generation**: MIDI files are created alongside MP3 exports
2. **Multi-track Format**: Separate MIDI tracks for each instrument
3. **Standard Format**: Compatible with all major DAWs (FL Studio, Ableton, Logic Pro, etc.)

### Usage
1. Generate a song as usual
2. After generation completes, you'll receive two download links:
   - MP3 file (audio)
   - MIDI file (composition data)
3. Download the MIDI file
4. Import it into your favorite DAW for further editing

### MIDI File Contents
The generated MIDI file includes:
- **Tempo Information**: BPM matching your selected genre
- **Instrument Tracks**: One track per selected instrument
  - Piano (Acoustic Grand Piano - Program 0)
  - Guitar (Acoustic Guitar - Program 24)
  - Bass (Acoustic Bass - Program 32)
  - Drums (Channel 10)
  - Violin (Program 40)
  - Saxophone (Program 64)
  - Trumpet (Program 56)
  - Synthesizer (Program 80)
  - Strings (Program 48)
  - Percussion (Program 115)
- **Note Data**: Musical notes with proper timing and velocity
- **Time Signatures**: Standard 4/4 time (varies by genre)

### Use Cases
- **Edit in DAW**: Modify melodies, rhythms, and arrangements
- **Change Instruments**: Assign different sounds in your DAW
- **Learn Music Theory**: Study the generated compositions
- **Remix**: Use as a starting point for your own tracks
- **Music Production**: Professional music creation workflow

### API Access
```bash
# Download MIDI file
curl -O http://localhost:5000/api/download-midi/{song_id}
```

## 🎧 Enhanced Audio Synthesis

### Overview
Improved audio generation with better instrument sounds and synthesis quality.

### Improvements
1. **Better Waveforms**: More realistic instrument sounds using advanced synthesis techniques
2. **TTS Integration**: Real vocal tracks instead of placeholder tones
3. **Genre-specific Processing**: Tailored effects for each musical genre
4. **Professional Mixing**: Multi-track mixing with automatic volume balancing
5. **Soundfont Ready**: Infrastructure for using SF2 soundfont files (optional)

### Current Synthesis Methods
- **Drums/Percussion**: Sine and square wave synthesis for kick, snare, hi-hat
- **Bass**: Lower octave sine waves with smooth envelope
- **Piano**: Clean sine wave synthesis
- **Guitar**: Sawtooth wave for more harmonic content
- **Synthesizer**: Square wave for electronic sound
- **Vocals**: Text-to-Speech (gTTS/pyttsx3)

### Soundfont Support (Optional)
For even better quality, you can use soundfont files:

1. Install FluidSynth:
   ```bash
   # Ubuntu/Debian
   sudo apt-get install fluidsynth
   
   # macOS
   brew install fluid-synth
   ```

2. Install Python binding:
   ```bash
   pip install pyfluidsynth
   ```

3. Download a soundfont file (SF2 format):
   - Free soundfonts: https://musescore.org/en/handbook/soundfonts
   - FluidR3_GM: Popular general MIDI soundfont

4. The app will automatically detect and use soundfonts when available

## 🛠️ Troubleshooting

### TTS Not Working
- **Check Internet**: gTTS requires internet connection
- **Install pyttsx3**: `pip install pyttsx3` for offline option
- **Check Logs**: Look for TTS error messages in console

### MIDI File Empty
- Ensure you selected at least one instrument
- Check that the song structure was generated correctly
- Verify MIDI file size (should be > 1KB)

### Poor Audio Quality
- Try using soundfonts for better instrument sounds
- Ensure ffmpeg is properly installed
- Check that sample rate is set correctly (44100 Hz)
